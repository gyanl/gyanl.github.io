{%- comment -%} The footer is fixed and the page scrolls over it, so body needs a run of padding exactly as tall as the footer for it to be revealed through — and the footer is sized by its own contents and its own padding, both of which change with the viewport. Measured here rather than guessed at. If this figure goes stale the page does not simply misalign, it covers the footer: body's runway is the footer's height less one corner radius, so a height reported SHORTER than the footer really is has the page ending too early and sitting over the top of it. That is what was cutting the mark in half in an in-app browser. {%- endcomment -%} {%- comment -%} The mark draws itself the first time a reader gets all the way to the bottom — the hero's reveal again, smaller, as a sign-off. Once per visit: a sign-off that repeats every time you nudge the scrollbar is a fidget, not a flourish. The path is retracted here rather than in the markup so that a reader without JavaScript gets the mark drawn, which is the state that matters. {%- endcomment -%}
